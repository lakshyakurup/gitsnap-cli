# Contributing to gitsnap-cli

## Getting started
1. Clone the repo
2. Install dependencies: `npm install`
3. Run tests: `npm test`

## Development
- Commands go in `src/commands/`
- Services go in `src/services/`
- Tests go in `tests/`

## Submitting changes
1. Create a feature branch
2. Make your changes
3. Run tests
4. Submit a pull request
