# gitsnap-cli API

## Core Functions

### runCli(args)
Main CLI entry point.

### snapshotCommand(args, options)
Creates a snapshot of git state.

### exportCommand(args)
Exports snapshot to file.

## Git Functions

### getStatus()
Returns git status output.

### getDiff(options)
Returns git diff output.

### getBranch()
Returns current branch name.
